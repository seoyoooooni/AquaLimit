# AquaLimit 기술 설계

## 1. 전체 흐름

`InSAR 변형 시계열 + 관측정 수위 + 취수 기록 + 지질자료 → 모델 보정(역산) → 파라미터 앙상블 → 대리모델 → 강건 최적화 → 취수계획·불확실성·실행 불가 판정`

새 위성 관측이 들어오면 보정 단계부터 다시 실행해 파라미터 앙상블을 갱신한다.

## 2. 모듈 ① 위성 관측으로 지하 상태 추정

### InSAR 변형

- 입력: Sentinel-1 기반 변형 시계열. 공개 처리 결과가 있으면 우선 사용하고, 없으면 자체 처리한다.
- InSAR는 위성 시선 방향(LOS) 변위를 측정한다. 수직 변위로 쓰려면 상승·하강 궤도 결합 또는 수평 변위 무시 가정이 필요하며, 사용한 방법을 기록한다.
- 관측 기준점, 대기 오차, 결맞음 저하 구간을 품질 정보로 함께 보존한다.

### 역산(모델 보정)

- 추정 대상: 구역별 탄성·비탄성 저류계수, 수리전도도, 압축층 두께 관련 파라미터.
- 관측: 격자별 InSAR 변위 시계열, 관측정 수위.
- 방법: 목적함수(관측-모델 오차) 최소화로 시작하고, 불확실성은 앙상블 기반 방법(예: 앙상블 칼만 계열 또는 여러 초기값 보정)으로 파라미터 분포를 얻는다. 방법은 첫 2주 실험 후 확정한다.
- 출력: 파라미터 앙상블(N개 세트). 이후 모든 계산은 앙상블 전체에 대해 수행한다.

## 3. 모듈 ② 취수계획 변경 시 미래 계산

### 물리모델

- MODFLOW 6의 지하수 흐름과 CSUB(압축층 침하) 패키지를 사용하고, Python에서는 FloPy로 모델을 생성·실행한다.
- 초기 범위는 한 지역의 단순화된 층 구조다. 층 구성과 경계 조건은 [검증 지역 선정](REGION_SELECTION.md) 후 정한다.
- 10/12: 가상 대수층을 MODFLOW 6 + CSUB로 구현(2개 층, 누수, 비탄성 압축). 실제 지역 모델은 CVHM2 층 구조를 사용한다.

### 대리모델 (AI)

최적화와 불확실성 계산은 물리모델을 수천 번 호출해야 한다. MODFLOW 6 + CSUB 1회 실행이 약 5초(가상 대수층 76×76×2 격자, 2년)이므로, 10/12 MODFLOW 실험(가상 땅 10곳 × 앙상블 30)에 약 45분이 걸렸다. 그래서 물리모델 실행 결과로 학습한 대리모델을 둔다.

| 단계 | 방법 | 용도 |
|---|---|---|
| 기준 | 응답 행렬: 취수정별 단위 취수 변화에 대한 관리 지점 수위·침하 응답 | 선형 근사, 최적화 기준선 |
| 고도화 | **지역별 신경망 대리모델**: 그 지역 MODFLOW를 땅속 성질·취수 시나리오를 바꿔 수천 번 실행한 결과로 학습 | 비선형(과거 최저 수위 아래 비탄성 압축) 반영, 1회 계산 수 ms |

- 입력: 땅속 성질(앙상블 구성원 파라미터), 과거 수위 상태(선행압밀수위), 계획 기간 우물별 취수량, 함양(날씨 시나리오).
- 출력: 관리 지점 침하·수위, 필요하면 격자 전체 침하 지도.
- 학습 자료: 파라미터를 사전분포에서 뽑고(라틴 하이퍼큐브), 취수량을 무작위로 바꿔 MODFLOW를 실행. 지역당 약 2,000~5,000회, 하룻밤 계산.
- 검증: 학습에 쓰지 않은 MODFLOW 실행과 비교한 오차를 관리 지점별로 기록한다. 최종 계획은 MODFLOW로 다시 실행해 확인한다.
- AI는 땅속을 직접 아는 모델이 아니라 **물리모델을 빠르게 흉내 내는 모델**이다. 새 지역마다 그 지역 위성·관측정 자료로 보정하는 단계는 그대로 필요하다.

### 지역 자동화 파이프라인

“어느 지역이든” 같은 절차로 서비스를 만들 수 있도록 지역 범위만 입력하면 나머지를 자동으로 수행한다.

`지역 범위 입력 → 공개 자료 자동 수집(InSAR, 관측정, 시설, 유전, 강수) → MODFLOW 모델 자동 생성(층 구조는 기존 지역 모델에서) → 역산·앙상블 → 지역 전용 AI 대리모델 학습 → 실시간 계획`

| 단계 | 현재 상태 |
|---|---|
| 자료 수집 | `real/fetch_data.py` (범위 상수만 바꾸면 다른 지역 수집, 10/12) |
| 물리모델 생성 | `synthetic/mf6_truth.py` (가상, 10/12), `real/real_model.py` (실제 지역, CVHM2 층 구조, 10/13) |
| AI 대리모델 | `real/surrogate_real.py` (10/13): MODFLOW 600회 학습, 침하 오차 0.14mm(R² 0.997), 1,000개 앙상블 0.1초 |

### 날씨·외부 요인

| 요인 | 영향 경로 | 반영 방법 |
|---|---|---|
| 강수 | 함양 → 수위 상승 → 침하 감소 | MODFLOW 함양(RCH). 강수: NOAA Lost Hills 관측소(일별), PRISM 월별 격자. 함양 초기값: CVHM2 |
| 가뭄 | 수로 공급 감소 → 지하수 취수 증가 | 습한 해·보통 해·가뭄 해 수요·함양 시나리오를 앙상블에 포함 |
| 온도·대기 | 위성 측정 오차(대기 지연, 구조물 열팽창) | 공개 자료의 보정 사용, 남는 오차는 관측 잡음으로 처리 |
| 다른 침하 원인 | 석유 생산 침하 등 | 유전 경계 격자 역산 제외 또는 별도 침하원 |

## 4. 모듈 ③ 불확실성을 반영한 취수계획

- 결정 변수: 취수정별·기간별 취수량, 대체 용수 구매량.
- 목적: 취수 비용 + 대체 용수 비용 최소화.
- 제약: 수요 충족, 취수정 용량, 관리 지점의 수위 하한·침하 상한.
- 불확실성: 파라미터 앙상블의 각 시나리오에서 제약을 평가한다. 기본은 모든 시나리오 충족(강건 제약)이며, 허용 위반 확률을 두는 기회제약 방식을 비교 옵션으로 둔다.
- 실행 불가: 대체 용수 상한까지 써도 제약을 만족할 수 없으면 해를 만들지 않고 실행 불가와 원인이 된 제약을 반환한다.
- 풀이: 응답 행렬 기준에서는 선형계획(LP)으로 풀고, 신경망 대리모델에서는 비선형 최적화 또는 반복 선형화로 푼다.

## 5. 출력과 화면

| 화면 | 내용 |
|---|---|
| 입력 | 수요, 관리기준, 단가, 계획 기간 |
| 계획 | 취수정별 주간 취수량 표, 대체 용수량, 총비용 |
| 위험 | 관리 지점별 수위·침하 예측 범위(앙상블 분포) |
| 자료 부족 | 파라미터 불확실성이 큰 구역, 추가 계측 후보 |
| 비교 | 기존 계획 대비 비용·기준 초과 빈도 |

## 6. 기술 스택 후보

Python, FloPy·MODFLOW 6, NumPy·pandas·xarray, PyTorch(대리모델), SciPy 또는 Pyomo + 오픈소스 LP 솔버, Streamlit 또는 웹 프레임워크(팀 역량에 따라 결정). 버전은 개발 환경 구성 시 고정한다.
