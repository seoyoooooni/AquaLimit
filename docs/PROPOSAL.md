# AquaLimit 기획서

버전 0.1 · 2026-09-30 · 상태: 기획 초안

## 1. 문제

지하수를 과도하게 뽑으면 점토층 등 일부 지층이 압축돼 지반이 내려앉을 수 있다. 이 변형에는 수위가 회복되면 되돌아가는 탄성 변형과 되돌아가지 않는 비탄성(영구) 변형이 있다. USGS 지하수 모델도 두 압축을 구분해 계산한다.

취수정을 여러 개 운영하는 사업자에게는 두 비용이 충돌한다.

- 취수를 지나치게 줄이면 대체 용수 구매비가 늘거나 공급이 부족해진다.
- 계속 취수하면 지반침하와 시설 손상 위험이 커진다.

캘리포니아 수자원국(DWR)은 침하로 수로 통수 능력이 줄고 에너지·유지보수 비용이 늘어난다고 설명하며, 2021년 침하로 잃은 수송 능력 복구를 위한 1억 달러 규모 지원사업을 시작했다. 이는 문제에 실제 예산이 투입된다는 근거이며 이 제품의 시장 규모가 아니다.

## 2. 첫 고객 가설

여러 취수정을 운영하는 수도사업자·산업용수 공급사업자 중, 침하에 취약한 대수층 위에 있고 취수량·수위 기록을 보유한 사업자.

실제 구매 주체·예산·의사결정 절차는 확인하지 않았다. [사업 모델](BUSINESS_MODEL.md)의 가설 검증 순서를 따른다.

## 3. 제품 입력과 출력

입력: 계획 기간의 필요 수량, 취수정 목록과 용량, 수위·침하 관리기준, 대체 용수 단가.

| 출력 | 고객이 내릴 결정 |
|---|---|
| 취수정별 주간 권장 취수량 | 어느 우물의 취수를 줄이고 늘릴지 |
| 대체 용수 필요량과 총비용 | 외부에서 물을 얼마나 구매할지 |
| 예상 수위·침하 범위와 불확실성 | 계획을 승인할지, 더 보수적으로 운영할지 |
| 현재 자료로 판단하기 어려운 구간 | 어디를 추가로 계측할지 |
| 실행 불가 판정 | 관리기준과 수요를 동시에 만족하는 계획이 없음을 알림 |

## 4. 핵심 기능

1. **위성 관측으로 지하 상태 추정:** InSAR 지표 변형과 관측정 수위·취수 기록·지질자료를 결합해 지층의 압축 특성과 수리 특성을 보정한다. 위성이 지하수를 직접 관측하는 것이 아니라, 지표 변형으로부터 지하 과정을 역으로 추정한다.
2. **취수계획 변경 시 미래 계산:** 과거와 다른 운영을 평가해야 하므로 시계열 예측이 아니라 지하수 흐름·지층 압축 물리모델(MODFLOW 6 + CSUB)을 사용하고, 반복 계산을 빠르게 하는 대리모델을 개발한다. 물리모델은 기존 공개 도구이며 직접 개발했다고 주장하지 않는다.
3. **불확실성을 반영한 취수계획:** 관측오차와 지질 특성 불확실성을 반영한 여러 시나리오에서 계획을 평가하고, 관리기준을 지키면서 총비용이 최소인 계획을 찾는다. 평균 조건에서만 좋은 계획은 걸러낸다.

상세는 [기술 설계](TECH_APPROACH.md)에 정의한다.

## 5. 해커톤 범위

| 포함 | 제외 |
|---|---|
| 한 지역, 소수 취수정, 주간 또는 월간 계획 | 광역·다지역 운영 |
| 공개 InSAR 자료 또는 자체 처리 1개 경로 | 여러 위성·처리 체인 비교 |
| 물리모델 1개와 대리모델 | 3차원 정밀 지질 모델링 |
| 4단계 비교 실험 | 실제 사업자 운영 적용 |
| 웹 데모(입력 → 계획 → 불확실성 → 비용) | 계정·다중 사용자·실시간 연동 |

## 6. 기존 서비스·연구와의 관계

| 이미 존재하는 것 | AquaLimit이 개발하고 검증할 것 |
|---|---|
| 상용 InSAR 변형 관측 서비스 | 관측 결과를 취수정별 운영 결정으로 연결 |
| 지하수·침하 시뮬레이터 | 새 위성 관측이 들어올 때 모델을 갱신하는 절차 |
| 침하 제약을 둔 취수 최적화 연구 | 관측·모델 오차를 반영한 계획과 비용 비교를 반복 제공 |

침하 제약 취수 최적화는 이미 연구된 주제이므로 ‘세계 최초’를 주장하지 않는다. 신규성은 갱신 방법, 불확실성 처리, 운영 제품으로 입증한다. 동일한 상용 제품이 없다는 조사는 완료하지 않았다.
