# AquaLimit 사업 모델

버전 0.1 · 2026-09-30 · 상태: 가설, 고객 검증 전

## 1. 고객과 가치

| 고객 후보 | 얻는 것 |
|---|---|
| 다수 취수정을 운영하는 수도사업자 | 침하 기준을 지키는 취수 배분, 대체 용수 비용 절감 근거 |
| 산업용수 공급사업자 | 공급 안정성과 시설 침하 위험의 동시 관리 |
| 지하수 관리기관 | 관할 지역 취수 계획 검토 근거, 추가 계측 우선순위 |

## 2. 수익 구조

- 초기 지역 모델 구축비: 지역별 자료 수집·모델 보정 작업.
- 연간 운영 라이선스: 위성 관측 갱신, 계획 산출, 보고서.

고객별 보정 작업이 많으므로 저가 범용 앱으로 판매하지 않는다. 가격과 구매의향은 검증하지 않았다.

## 3. 검증할 가설

| 가설 | 첫 검증 방법 | 결과에 따른 결정 |
|---|---|---|
| 사업자가 침하를 취수 계획에 반영해야 하는 상황이 있음 | 공개 보고서·규제 문서 조사, 담당자 질문 | 없으면 고객을 관리기관으로 변경 |
| 현재 방법은 수작업 또는 외부 용역 | 담당자 질문 | 기존 도구가 충분하면 차별점 재검토 |
| 위성 갱신의 가치 | 관측 갱신 주기와 계획 주기 비교 | 갱신 가치가 낮으면 연간 점검 상품으로 축소 |
| 구매 가능 예산 | 유사 용역 규모 조사 | 가격대 설정 |

## 4. 시장 설명 원칙

- DWR 지원사업 규모 등 공공 예산 사례는 문제의 실재 근거로만 쓰고 시장 규모로 쓰지 않는다.
- 국내 시장은 [검증 지역 선정](REGION_SELECTION.md)의 국내 사례 조사 결과를 확인한 뒤 서술한다.
