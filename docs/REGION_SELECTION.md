# AquaLimit 검증 지역 선정

버전 0.1 · 2026-09-30 · 상태: 후보 조사 전

## 1. 선정 기준

| 기준 | 이유 |
|---|---|
| 지하수 취수로 인한 침하가 관측·보고된 지역 | 문제가 실재해야 검증 의미가 있음 |
| InSAR 변형 시계열 확보 가능 | 모듈 ① 입력 |
| 관측정 수위 시계열 확보 가능 | 보정·검증 |
| 취수 기록 또는 합리적 추정 가능 | 최적화 대상 |
| 기존 지하수 모델·지질 자료 존재 | 층 구성 시간 단축 |
| 국내 사업 설명과의 연결 | 심사에서 적용 시장 설명 |

## 2. 후보

| 후보 | 장점 | 확인할 것 |
|---|---|---|
| 캘리포니아 센트럴밸리 | 침하 문제·공개 InSAR·관측 자료가 알려져 있음 | 관정별 취수 기록, 대상 소지역 범위 |
| 국내 지하수 의존 지역 | 국내 사업 설명에 유리 | 지하수 취수로 인한 침하 관측 사례 존재 여부, 관측정 밀도 |
| 해외 대도시권(자카르타, 멕시코시티 등) | 지하수 취수 침하로 알려진 지역, 해외 시장 설명 | 공개 자료 접근성 |

## 3. 결정 방법

1주차에 후보별로 1장의 기준 충족표를 만든다. 필수 자료(InSAR, 수위, 지질)가 모두 확보되는 지역 중 취수 기록 수준이 가장 좋은 곳을 선택한다. 국내 후보가 필수 자료를 충족하지 못하면 검증은 해외 지역에서 하고, 국내는 적용 시장으로만 설명한다.
