# AquaLimit 검증 계획

## 1. 비교 실험

같은 수요·제약 아래 네 방식을 비교한다.

| 방식 | 모델 보정에 쓰는 자료 | 불확실성 |
|---|---|---|
| E1 기존 취수계획 | 없음(실제 또는 기준 계획 그대로) | 없음 |
| E2 지상 관측만 사용한 최적화 | 관측정 수위 | 단일 파라미터 |
| E3 위성 관측까지 사용한 최적화 | 수위 + InSAR | 단일 파라미터 |
| E4 위성 + 불확실성 반영 최적화 | 수위 + InSAR | 파라미터 앙상블 |

E2 대비 E3는 “위성을 넣으니 무엇이 좋아졌나”, E3 대비 E4는 “불확실성 처리가 왜 필요한가”에 답한다.

## 2. 평가 지표

| 지표 | 정의 |
|---|---|
| 공급 부족량 | 수요 대비 미충족 수량 |
| 총비용 | 취수 비용 + 대체 용수 비용 |
| 관리기준 초과 빈도 | 검증 시나리오에서 수위·침하 기준을 넘은 비율 |
| 계산 시간 | 계획 1회 산출 시간 |
| 예측 오차 | 보정 기간 이후 관측 대비 수위·침하 예측 오차 |

## 3. 절차

1. 자료를 보정 기간과 검증 기간으로 나눈다.
2. 보정 기간 자료로 E2~E4 모델을 보정한다.
3. 검증 기간의 수위·침하 예측 오차를 비교한다. 이는 관측으로 확인하는 성능이다.
4. 각 방식의 최적 계획을 산출하고, 보정에 쓰지 않은 파라미터 시나리오 집합에서 관리기준 초과 빈도와 비용을 평가한다. 이는 시뮬레이션 결과다.
5. 대리모델 계획을 물리모델로 재실행해 차이를 기록한다.

실행하지 않은 계획의 효과는 시뮬레이션 결과로만 표시하고, 관측으로 검증한 예측 성능과 구분한다.

## 4. 합성 검증

실제 자료와 별도로, 파라미터를 알고 있는 합성 대수층을 만들어 역산이 참값을 복원하는지 확인한다. 실제 자료 확보가 늦어져도 모듈 ①~③을 합성 자료로 먼저 개발·검증한다.

## 5. 실행 불가 판정 테스트

수요를 크게 올리거나 관리기준을 강하게 설정한 입력에서 해를 만들지 않고 실행 불가와 원인 제약을 반환하는지 확인한다.
