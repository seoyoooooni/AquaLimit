## 4. 판단 관문

| 관문 | 판단 자료 | 미통과 시 |
|---|---|---|
| R1 | 필수 자료 충족표 | 합성 대수층 + 공개 InSAR만으로 진행, 실제 운영 개선 주장 제외 |
| R2 | 합성 자료에서 역산 복원 오차, 최적화 해 산출 | 모델 단순화(층 수·구역 수 축소) |
| R3 | InSAR 추가 시 예측 오차 변화, 단순 예측(변화 0·추세 연장)과 비교 | 차이가 없으면 결과 그대로 보고하고 원인 분석 |
| 최종 모델 | v3 검증 점수(GPS), 자연 실험 방향 일치, 파라미터가 범위 끝에 붙는지 | 계획·정책은 응답(취수 변화의 효과)만으로 결정되므로 배경 예측 오차와 분리해 보고 |
| R4 | E1~E4 지표, AI 대리모델 오차 | AI 오차가 크면 제외하고 응답 행렬 + MODFLOW 재검증으로 진행 |
| R5 | 문서·데모·수치 일치 | 불일치 항목 삭제 |
