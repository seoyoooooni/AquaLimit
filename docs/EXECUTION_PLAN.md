# AquaLimit 실행 계획

## 1. 역할

| 역할 | 책임 | 산출물 |
|---|---|---|
| 위성·데이터 | InSAR·수위·취수 자료 수집과 정리 | 데이터 manifest, 품질표 |
| 모델 | MODFLOW 6·CSUB 모델, 역산 | 보정된 파라미터 앙상블 |
| 최적화·AI | 대리모델, 강건 최적화 | 계획 산출 코드, 비교 실험 결과 |
| 제품·사업 | 웹 데모, 고객 가설 조사 | 화면, 사업 모델 |

## 3. 판단 관문

| 관문 | 판단 자료 | 미통과 시 |
|---|---|---|
| R1 | 필수 자료 충족표 | 합성 대수층 + 공개 InSAR만으로 진행, 실제 운영 개선 주장 제외 |
| R2 | 합성 자료에서 역산 복원 오차, 최적화 해 산출 | 모델 단순화(층 수·구역 수 축소) |
| R3 | InSAR 추가 시 예측 오차 변화 | 차이가 없으면 결과 그대로 보고하고 원인 분석 |
| R4 | E1~E4 지표 산출, AI 대리모델 오차 | AI 대리모델 오차가 크면 제외하고 응답 행렬 + MODFLOW 재검증으로 진행 |
| R5 | 문서·데모·수치 일치 | 불일치 항목 삭제 |
