## 1. 새 장: 실험 12 · 모델 개선 시도 11개 (11장 뒤)

**제목** 모델을 더 정확하게 만들 수 있나? 11가지로 바꿔 봤다

| 바꾼 것 (모델 구조) | 맞춘 자료 (보정) | 테스트 자료 |
|---|---|---|
| 유전 침하 성분 · 파일럿 포인트(구역 9개 → 점 33개) · 수로물 의존도 안·밖 · 보정 위성 OPERA, 조합 포함 11개 | 2015.7~2019.12 위성(DWR 또는 OPERA) + 관측정 | 연습 시험: 2020~22 OPERA 위성, 수로 2km 칸 |

| 모델 | 수로 2km 오차 | 전체 수준(편향) | 칸별 분포(편향 뺀 나머지) |
|---|---|---|---|
| v3 (현재) | **14.0** | +2.0 | 13.9 |
| 유전 성분 | 15.6 | +9.1 | 12.7 |
| 파일럿 포인트 | 15.9 | +10.9 | **11.7** |
| 유전 + 파일럿 + OPERA 보정 | 15.8 | +9.8 | 12.4 |
| (비교) 위성 추세 연장 | 10.4 | | |

알게 된 것
- **유전 침하가 섞여 있다.** Lost Hills 유전 경계에서 연 14mm, 1.3km마다 약 37%로 줄어드는 성분. 습한 해·금지 후에도 계속 꺼진 수로 GPS 4곳이 모두 유전 2.5km 안이다.
- **칸별 분포는 고쳐진다.** 파일럿 포인트로 13.9 → 11.7mm, 지역 전체 34.2 → 30.4mm.
- **공통으로 틀리는 곳: 수로 근처 가뭄 반응.** 실제 수로 근처는 가뭄에 1.3배, 바깥은 3배 빨라졌는데 모델은 수로 근처의 큰 침하를 '무른 점토'로만 설명해 가뭄 반응을 크게 잡는다(편향 +8~+12mm).

그래서 → **v3 확정.** 다음 개선은 모델 구조가 아니라 자료: 가뭄 해 실제 취수(관리기관 계량), 유전 생산량, 수로 근처 관측정.

각주: 판정 기준은 결과 보기 전에 정함(수로 2km 오차가 v3보다 작고 GPS P544가 크게 나빠지지 않을 것) · 이긴 후보가 없어 최종 시험은 보지 않음 · 후보당 맥에서 5~12분

## 4. 예상 질문 (추가·수정)

| 질문 | 답 |
|---|---|
| 금지구역 안에서 몰래 뽑았다는 건가? (수정) | 단정하지 않는다. 위성으로는 금지구역 안이 밖보다 좋아지지 않았다(+2.9). 하지만 금지가 없던 해에도 이 차이는 수로 배분율 변화를 따라 −7~+10으로 움직이고, 이번엔 배분율이 올라 금지 없이도 약 +1.1이 예상된다. 남는 +1.8은 해마다 흔들리는 정도다. 그래서 '금지 효과가 위성에 안 보인다'까지만 말하고, 초록 원 10곳을 먼저 확인할 곳으로 준다. 확정은 유량계로 한다. |
| 유전 때문 아닌가? (새) | 일부는 그렇다. 수로 2km 안에서 Lost Hills 유전 1km 안 칸은 물이 많던 2023년에도 연 23mm, 3~6km 칸은 연 4mm로 꺼졌다. 습한 해에도 계속 꺼진 GPS 4곳이 모두 유전 2.5km 안이다. 다만 위성 이중차분은 유전 근처 칸을 빼도 그대로다(+3.3~+4.3) — 일정한 유전 침하는 '후 − 전'에서 빠진다. 모델(v3)은 유전 칸만 빼고 있어, 유전 성분을 넣은 후보(v4-oil)도 시험했지만 총점은 v3보다 나빴다. |
| 추세보다 못한 예측을 어떻게 고칠 건가? (수정) | 구조 후보 11개를 시험했다(유전 성분, 파일럿 포인트, 수로물 안·밖, OPERA 보정). 칸별 분포 오차는 파일럿 포인트로 13.9 → 11.7mm로 줄었지만, 모두 수로 근처 가뭄 반응을 크게 잡아 총점은 v3를 못 넘었다. 수로 근처는 실제로 가뭄에 1.3배, 바깥은 3배 빨라졌는데, 지금 취수 추정은 같은 해 모든 농경지의 지하수 비율이 같다. 가뭄 해 실제 취수 자료가 핵심이고, 그래서 첫 고객인 관리기관과의 자료 협력이 기술 로드맵 1단계다. 그때까지 '지금처럼 하면' 전망은 위성 추세로 낸다. |
| 결과 보고 기준을 바꾼 것 아닌가? (새) | 판정 기준(수로 2km 오차, GPS P544)은 실험 전에 정했고 바꾸지 않았다. 파일럿 포인트 후보는 지역 전체로는 v3보다 좋았지만(30.4 vs 34.2mm) 기준이 아니라서 채택하지 않았다. 이긴 후보가 없어 최종 시험(2023~26 GPS)은 보지 않았다. |
| 실제 취수 자료가 있으면 정말 좋아지나? (새) | 보장은 못 한다. 근거는 이렇다: 2020~22 가뭄에 모델 입력 취수는 수로 근처 1.37배·바깥 1.24배로 거의 같게 늘었지만, 실제 침하는 수로 근처 1.3배·바깥 3배였다. 지역마다 다른 가뭄 반응이 입력에 없다. 수로물 의존도를 안·밖으로 나눈 후보(v4-sw2)는 2015~19 보정 자료로는 이 차이를 잡지 못했다. |
