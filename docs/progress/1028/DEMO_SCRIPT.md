## 예상 질문 (짧은 답)

| 질문 | 답 |
|---|---|
| 금지 후 '빨라졌다'고 하지 않았나? | 처음엔 1년 단위가 아닌 구간으로 쟀다. 수로 GPS는 여름에 오르고 겨울에 내려가는 계절 변동이 있어 같은 달끼리 1년 단위로 다시 쟀고, 정확한 표현은 "줄지 않았다"다. |
| 위성 자료를 왜 바꿨나? | DWR 공급 자료가 2023년 이후 P544·Q204에서 GPS와 반대(상승)였다. NASA OPERA는 5곳 모두 GPS와 같은 방향, 오차 중앙값 17.0 → 8.3mm. |
| 금지구역 안에서 몰래 뽑았다는 건가? | 단정하지 않는다. 위성 이중차분과 모델 모두 이상 신호를 보이지만, 늦게 눌리는 점토 몫이 섞여 있고 모델 추정은 쓰는 위성 자료에 따라 갈린다(안 1.36배 vs 1.08배). '먼저 확인할 곳' 목록으로 쓰고 확정은 유량계로 한다. |
| 절약액은 실제로 아낀 돈인가? | 아니다. 같은 모델·같은 기준에서 금지 확대안과 비교한 시뮬레이션이다. 금지 반경과 AquaLimit 계획 모두 MODFLOW 앙상블로 직접 돌려 '모든 구성원·모든 수로 지점 기준 안'(같은 신뢰도)을 확인했다. |
| 선형 계산으로 푼 계획을 믿을 수 있나? | 그대로는 못 믿는다. MODFLOW로 돌리면 모든 지점 기준 확률이 60~97%였다. 그래서 MODFLOW로 확인하고 어긋난 만큼 고쳐 다시 푸는 과정을 3~4번 거쳐 100%로 맞춘다(비용 8~15% 증가). 발표 숫자는 모두 이 결과다. |
| 연습 시험 정답을 DWR에서 OPERA로 바꾼 건 결과 맞추기 아닌가? | 근거는 독립 자료인 GPS다. 연습 기간에 GPS가 있는 P544에서 DWR는 GPS 침하의 절반(13.6 vs 27.8mm), OPERA는 24.9mm. 모델은 다시 보정하지 않고 채점만 다시 했고, 세 정답(DWR·OPERA·GPS) 모두에서 v3가 1등이다. 바꾼 뒤에는 오히려 추세 연장이 모델보다 좋아졌다(우리에게 유리한 쪽이 아님). |
| 추세보다 못한 예측을 어떻게 고칠 건가? | 틀리는 원인은 칸마다 꺼지는 정도의 분포다(9개 구역으로만 나눔: P544는 2배 크게, 수로 바로 옆은 작게). 예측 뒤에 칸별 배수를 곱해 보니 P544는 21.0 → 5.2mm로 맞았지만 수로 칸은 나빠져(14.0 → 18.2) 탈락시켰다. 다음은 칸별 점토 성질을 모델 안에서 위성·GPS로 함께 보정하는 것이다. 그때까지 '지금처럼 하면' 전망은 위성 추세(GPS 오차 7.2mm)로 낸다. |
| 다른 지역에도 되나? | 자료 수집·모델 생성 코드는 범위만 바꾸면 돌지만, 보정·검증은 지역마다 다시 한다. 다음 지역은 Friant-Kern Canal 주변. |
| 국내는? | 엔진은 그대로, 입력을 농림위성(2026.7 발사)·수자원위성(2027)으로 바꾼다. 우주항공청·NIA 위성 지반변위 공모가 이미 있었다(14개 컨소시엄). |
| 가격 근거는? | 아직 가설이다. 관개기 한 번 절약액(수백만 달러)과 보호관찰 수수료가 비교 기준이다. 메일로 관리기관에 확인한다. |
