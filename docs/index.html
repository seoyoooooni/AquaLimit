이 숫자는 무엇을 뜻하나?

실제 자료

DWR 신고 농업용 우물 A~F의 위치·깊이, 위성·관측정·GPS 관측을 모델 구축과 검증에 사용했습니다.

계획에 둔 가정

여섯 우물을 한 사업자가 운영한다는 설정, 신고 양수량이 없는 우물의 대표 용량, 미래 날씨, 외부 용수 단가, 사업자 추가 침하 한도입니다.

해석 범위

2026년 4월 이후는 선택한 시나리오로 이어 계산한 예측입니다. `0/3`은 계획에 사용한 모델 세 개에서 초과가 없다는 뜻이며 실제 초과 확률을 뜻하지 않습니다.

이 페이지는 기본 조건의 미리 계산된 발표용 결과입니다. 다른 월·날씨·우물 조건을 다시 계산하려면 Streamlit 실행 앱에서 MODFLOW를 돌려야 합니다.
