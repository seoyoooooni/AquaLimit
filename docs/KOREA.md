# AquaLimit 국내 적용

미국 실증(California Aqueduct)에서 쓴 계산 엔진은 그대로 두고, **입력 자료만 국내 자료·국산 위성으로 바꾼다.** 엔진이 푸는 문제는 같다: "관리 기준(침하·수위)을 지키면서 필요한 물을 가장 싸게 얻으려면 어느 관정에서 얼마나 뽑아야 하나."

## 1. 입력 자료 바꾸기

| 엔진 입력 | 미국 실증에서 쓴 것 | 국내에서 쓸 것 | 상태 |
|---|---|---|---|
| 지표 변위(침하) | NASA OPERA(Sentinel-1, 30m, 무료) | Sentinel-1(한반도도 관측) → **수자원위성(차세대중형위성 5호, 레이더)**, 공사 현장은 **아리랑 6호**(고해상도 레이더)·상용 X밴드 | 수자원위성 2027 발사 목표, 아리랑 6호 2027 2분기 예상 |
| 밭별 작물 물 사용(→ 취수 추정) | Landsat NDVI × gridMET 기준증발산 | **농림위성(차세대중형위성 4호)**: 5m, 폭 120km, 한반도 3일 주기 | 2026.7.7 발사, 2027 상반기 본격 운영, 민간 단계적 개방 |
| 기상(기온·습도·바람·일사) | gridMET | 기상청 종관·방재 기상관측(ASOS·AWS) | 공개 |
| 관측정 수위 | DWR 정기 측정 관측정 30곳 | 국가지하수관측망, 지자체 관측망(제주 151곳, 시간 단위) | 공개(일부 기관 요청) |
| 우물 위치·양수량 | DWR 우물 신고 자료(공개) | 지하수 개발·이용 허가·신고 자료(지자체) | 기관 협조 필요 |
| 지층 구조 | USGS CVHM2(공개 지하수 모델) | 국토지반정보 시추 자료, 지하수 기초조사 | 공개(지역별 밀도 다름) |
| 검증용 GPS | Nevada Geodetic Lab(수로 GPS 5곳) | 국토지리정보원 위성기준점(CORS) | 공개 |
| 관리 기준 | 이웃 GSA 수로 침하 기준 연 0.5인치 | 지하안전법 공사 관리기준, 지하수 보전구역 수위 기준 | 법령·현장별 |

## 2. 국내 수요 근거 (2025~2026)

| 근거 | 내용 | 뜻 |
|---|---|---|
| 공공 발주 | 우주항공청·NIA '위성영상 기반 지반변위 위험지역 분석' 공모(2026.6): 14개 컨소시엄 경쟁, 제주 1위(5.33억 원, 레이더 위성 변위 + 시간 단위 지하수위 + 노후 관로 → 10m 격자 위험도, 2027 시범 운영) | 위성 + 지하수 자료 결합 사업에 정부가 돈을 낸다 |
| 지자체 도입 | 서울 중구 위성 싱크홀 상시 감시(2025.5) | 위성 침하 감시가 행정 서비스가 됐다 |
| 사고 | 광명 신안산선 공사장 붕괴(2025.4, 하루 1,600톤+ 지하수 배출 보도), 2015~2024 지반침하 2,119건 | 공사 중 배수(지하수 양수)와 침하가 직접 연결 |
| 가뭄 | 제주 서부 지하수위 2026년 1~8월 전년보다 1.6m 낮음, 누적 강수 평년의 77%(서부) | 날씨에 따라 취수 배분을 바꿔야 하는 상황이 국내에도 있다 |

## 3. 시범 지역 두 곳 (제안)

| | A. 도심 대형 굴착공사(민간) | B. 제주 지하수 취수 배분(공공) |
|---|---|---|
| 관리 기준 | 주변 지반 침하 한도(공사 관리기준) | 관측정 수위 하한(해수 침투·고갈 방지) |
| 결정 | 배수정별 양수량·차수 보강 여부 | 농업용·상수도 관정별 취수 배분, 가뭄 시 감량 순서 |
| 위성 역할 | 고해상도 레이더(아리랑 6호·상용 X밴드)로 공사 전후 변위 | 수자원위성·Sentinel-1 변위, 농림위성으로 밭별 물 사용 |
| 엔진에서 바꿀 것 | 점토 압밀 → 모래층 변형·세굴(물리모델 교체 필요) | 침하 기준 → 수위 기준(엔진에 이미 있음: 미국에서 '임계수위 유지' 제약으로 시험) |
| 어려운 점 | 현장 규모(수백 m)가 위성 화소보다 작다 → 현장 계측 결합 | 화산암 대수층은 점토 압밀 침하가 작다 → 침하보다 수위 관리 중심 |

미국 실증에서 이미 시험한 기능 중 B에 바로 쓰이는 것: 날씨 시나리오(기온·강수·지표수 공급)에 따른 취수 배분, 수위 하한 제약, 실행 불가 판정("이 수요는 수위 기준 안에서 불가능하다, 추가 수원이 필요하다").

## 4. 발표용 한 줄

> "미국에서 NASA 위성으로 검증한 엔진을, 2026년 7월 발사한 농림위성과 2027년 수자원위성으로 입력만 바꿔 국내에 적용합니다. 국내에는 이미 위성 지반변위 위험 지도 공모가 나왔고, AquaLimit은 그 지도를 '어느 관정을 얼마나 줄일지'로 바꾸는 다음 단계입니다."

## 5. 확인할 것

- 수자원위성 레이더의 해상도·관측 주기·자료 개방 정책(K-water 수자원위성연구소 문의). 공개 기사에서 확인한 것은 2027 발사 목표, 레이더(전천후), K-water 지상운영체계뿐이다.
- 농림위성 산출물 중 증발산(또는 식생지수) 제공 여부와 민간 개방 시기.
- 지자체 지하수 이용 허가 자료의 관정별 양수량 공개 범위.
