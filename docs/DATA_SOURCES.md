# AquaLimit 데이터

버전 0.1 · 2026-09-30 · 상태 표기: 확인됨 / 확인 필요

## 1. 필요한 자료

| 자료 | 용도 | 필수 여부 |
|---|---|---|
| InSAR 변형 시계열 | 모델 보정, 검증 | 필수 |
| 관측정 수위 | 모델 보정, 검증 | 필수 |
| 취수정 위치·취수 기록 | 모델 입력, 최적화 대상 | 필수(없으면 합성 시나리오로 대체) |
| 지질·층 구조 | 모델 층 구성 | 필수 |
| 강수·함양 추정 | 경계 조건 | 선택 |
| 대체 용수 단가 | 비용 계산 | 필수(공개 요금 또는 가정값) |

## 2. 확보 경로 후보

| 자료 | 후보 경로 | 상태 |
|---|---|---|
| Sentinel-1 원자료 | ASF, Copernicus Data Space | 확인 필요: 대상 지역 장면 수·기간 |
| 처리된 InSAR 변형(캘리포니아) | 캘리포니아 DWR이 공개하는 InSAR 침하 자료 | 확인 필요: 기간·해상도·이용 조건 |
| 처리된 InSAR 변형(북미) | NASA OPERA 변위 제품 | 확인 필요: 제공 범위·기간 |
| 관측정 수위(캘리포니아) | DWR·USGS 공개 지하수위 자료 | 확인 필요 |
| 관측정 수위(국내) | 국가지하수정보센터 관측망 자료 | 확인 필요: 대상 지역 관측정 밀도 |
| 취수 기록 | 지역 지하수 관리기관 보고서, 사업자 제공 | 확인 필요: 관정별 공개 여부가 가장 큰 불확실성 |
| 지질 자료 | 기존 지역 지하수 모델, 시추 자료 | 확인 필요 |

## 3. 자료 원칙

- 원본은 수정하지 않고 저장하며 출처·수집일·해시를 기록한다.
- 관정별 취수 기록이 없으면 관측 자료는 모델 보정에만 쓰고, 최적화는 합성 취수 시나리오로 검증한다. 이 경우 결과를 실제 운영 개선으로 표현하지 않는다.
- 공개 자료의 재배포 조건을 확인한 뒤 데모에 포함한다.
