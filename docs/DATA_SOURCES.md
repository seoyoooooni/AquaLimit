| 자료 | 용도 | 필수 여부 |

| InSAR 변형 시계열 | 모델 보정, 검증 | 필수 |

| 취수정 위치·취수 기록 | 모델 입력, 최적화 대상 | 필수(없으면 합성 시나리오로 대체) |

## 3. 자료 원칙

- 원본은 수정하지 않고 저장하며 출처·수집일·해시를 기록한다.
- 관정별 취수 기록이 없으면 관측 자료는 모델 보정에만 쓰고, 최적화는 합성 취수 시나리오로 검증한다. 이 경우 결과를 실제 운영 개선으로 표현하지 않는다.
- 공개 자료의 재배포 조건을 확인한 뒤 데모에 포함한다.

## 4. 확보 현황 (10/12)

검증 지역(Aqueduct MP 195~215) 자료를 받아 [real/](../real/README.md)에 정리했다. InSAR 측정점 74,944개(2015.1~2026.4), 관측정 30곳(측정 1,831건), 수로 선형, 정밀측량점, 유전 경계.
