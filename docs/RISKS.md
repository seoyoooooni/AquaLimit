# AquaLimit 위험과 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| 관정별 취수 기록 미확보 | 실제 운영 개선을 보일 수 없음 | 합성 취수 시나리오로 최적화 검증, 표현 제한 |
| 수문지질 전문성 부족 | 모델 타당성 질문에 취약 | 기존 지역 모델·논문 구조를 따르고 출처 명시, 전문가 자문 요청 |
| InSAR 자체 처리 시간 | 일정 지연 | 공개 처리 결과 우선, 자체 처리는 필요한 경우만 |
| 역산 비유일성 | 파라미터 신뢰 저하 | 앙상블로 불확실성 표시, 합성 검증으로 복원력 확인 |
| 대리모델 오차 | 잘못된 계획 | 최종 계획 물리모델 재검증 |
| 국내 사례 부족 | 국내 시장 설명 약화 | 해외 검증 + 국내 적용 조건 명시 |
| 유전 침하 혼입(10/12 발견) | 수로 2km 이내 격자 39%가 유전 안. 석유 생산 침하를 지하수 침하로 오인하면 압축성 과대추정 | 유전 경계 격자 역산 제외 또는 별도 침하원으로 모델링 |
| 수로 옆 관측정 기록이 짧음(10/12 발견) | 다층 관측정이 2023~2025년 설치. 장기 비교 불가 | 보정·검증 기간을 2023년 이후로 맞추고, 장기 관측정(수로 4.6~8.6km)은 지역 보정에 사용 |
