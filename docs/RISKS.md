# AquaLimit 위험과 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| 관정별 취수 기록 미확보 | 실제 운영 개선을 보일 수 없음 | 합성 취수 시나리오로 최적화 검증, 표현 제한 |
| 수문지질 전문성 부족 | 모델 타당성 질문에 취약 | 기존 지역 모델·논문 구조를 따르고 출처 명시, 전문가 자문 요청 |
| InSAR 자체 처리 시간 | 일정 지연 | 공개 처리 결과 우선, 자체 처리는 필요한 경우만 |
| 역산 비유일성 | 파라미터 신뢰 저하 | 앙상블로 불확실성 표시, 합성 검증으로 복원력 확인 |
| 대리모델 오차 | 잘못된 계획 | 최종 계획 물리모델 재검증 |
| 국내 사례 부족 | 국내 시장 설명 약화 | 해외 검증 + 국내 적용 조건 명시 |
| 유전 침하 혼입(10/12 발견) | 수로 2km 이내 격자 39%가 유전 안. 석유 생산 침하를 지하수 침하로 오인하면 압축성 과대추정 | 유전 경계 격자 역산 제외 또는 별도 침하원으로 모델링 |
| 수로 옆 관측정 기록이 짧음(10/12 발견) | 다층 관측정이 2023~2025년 설치. 장기 비교 불가 | 보정·검증 기간을 2023년 이후로 맞추고, 장기 관측정(수로 4.6~8.6km)은 지역 보정에 사용 |
| 2023년 이후 InSAR 품질(10/12 발견) | DWR InSAR가 2023년 이후 GPS와 반대로(상승) 나옴. 그대로 쓰면 침하를 과소평가 | 2023년 이후 DWR 제외, GPS로 검증. **10/22: NASA OPERA로 교체 — GPS와 방향 5/5 일치, 오차 17.0 → 8.3mm.** 10/23: DWR 오류는 2020년 무렵부터(P544 2020~22 GPS 27.8, DWR 13.6mm) → 연습 시험 정답도 OPERA로. 서비스에 GPS 교차검증(자료 품질 검사) 기능 포함 |
| 불확실성 과소평가(10/12 확인) | E4 90% 범위가 GPS를 30%만 포함. 계획이 기준을 넘을 위험 | 10/13 대응: 되돌아보기 검증으로 잰 구조 오차를 더해 GPS 포함률 94%. 단 범위 계산이 실제 90%보다 넓게 잡히는 방식이라 다시 계산 필요 |
| 최근 침하 속도 과소예측(10/13 확인) | 검증 기간 GPS 예측이 단순 추세 연장(7.2mm)보다 부정확(E3 20.5mm). 계획 응답도 작게 볼 수 있음 | 단순 예측을 비교 기준으로 항상 함께 보고. 시작 상태(과거 가뭄 잔류 침하)·지연 배수 반영. **10/23:** 연습 시험 정답(DWR 2020~22)이 GPS의 절반만 잡는 것을 발견 → OPERA로 다시 채점: 모델 편향은 +2mm뿐(과대예측은 자료 탓), v3가 구조 후보 7개 중 1등으로 확정. 3년 누적은 추세 연장이 더 정확 → '지금처럼' 전망은 위성 추세, 계획 응답은 물리모델로 나눠 씀 |
| 선형 계획의 비선형 오차(10/23 확인) | 선형 응답으로 푼 '모든 지점 기준' 계획을 MODFLOW로 돌리면 모든 지점 기준 확률이 60~97%로 떨어짐. 절약액 비교도 신뢰도가 달라 불공정 | **해결(10/23):** 계획을 MODFLOW로 확인하고 비율로 고쳐 다시 풀기(3~4회) → 100%. 금지 반경도 MODFLOW로 직접 찾아 같은 신뢰도에서 비교(refine_plan.py). 다음 관개기 앙상블이 15개뿐이라 꼬리 위험은 구성원을 늘려 다시 확인 필요 |
| 가정 우물이 금지구역 안(10/13 확인) | 계획 우물 6개가 수로 양쪽 4km 취수 금지구역 안. 현실성 질문에 취약 | **해결(10/14):** 금지구역 밖 실제 신고 관정 6개로 교체, 정책 비교는 실제 우물 56개 |
| 관리 기준값 근거 부족 | 2mm/3개월은 가정값. “왜 2mm인가” 질문에 취약 | **해결(10/14):** 이웃 GSA의 같은 수로 최소기준 연 0.5인치(12.7mm). 사업자 몫 2mm는 여전히 가정 |
| AI 대리모델 오차(10/13 확인) | AI로 기준선에 맞춘 계획이 MODFLOW에서 7% 확률로 기준 초과 | AI 오차(0.2mm)만큼 여유를 두고 계획 → MODFLOW 확인 0%. 최종 계획은 항상 MODFLOW로 확인 |
| GPS 계절 변동(10/22 발견) | 수로 GPS가 여름에 올라가고 겨울에 내려감(수 mm~10mm대). 1년 단위가 아닌 구간으로 속도를 재면 '금지 후 가속' 같은 잘못된 결론 | 속도 비교는 같은 달 → 같은 달 1년 단위로. 10/28 원고 수정("빨라졌다" → "줄지 않았다"). 운영 모델은 OPERA(계절 변동이 작음)로 다시 보정 |
| 금지 반경 비교가 선형 계산(10/22) | 금지 확대안 비용·효과가 MODFLOW 직접 계산과 다를 수 있음 | 정책 비교에서 선형 예측과 MODFLOW가 맞는 것은 확인. 금지 확대안도 MODFLOW로 확인 예정 |
| 이행 점검 오해(10/22) | 위성으로 '위반'을 단정하면 신뢰·법적 문제 | 늦게 눌리는 점토 몫이 섞여 있으므로 '현장 확인 후보'로만 제공 |
