# AquaLimit 위험과 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| 관정별 취수 기록 미확보 | 실제 운영 개선을 보일 수 없음 | 합성 취수 시나리오로 최적화 검증, 표현 제한 |
| 수문지질 전문성 부족 | 모델 타당성 질문에 취약 | 기존 지역 모델·논문 구조를 따르고 출처 명시, 전문가 자문 요청 |
| InSAR 자체 처리 시간 | 일정 지연 | 공개 처리 결과 우선, 자체 처리는 필요한 경우만 |
| 역산 비유일성 | 파라미터 신뢰 저하 | 앙상블로 불확실성 표시, 합성 검증으로 복원력 확인 |
| 대리모델 오차 | 잘못된 계획 | 최종 계획 물리모델 재검증 |
| 국내 사례 부족 | 국내 시장 설명 약화 | 해외 검증 + 국내 적용 조건 명시 |
| 유전 침하 혼입(10/12 발견) | 수로 2km 이내 격자 39%가 유전 안. 석유 생산 침하를 지하수 침하로 오인하면 압축성 과대추정 | 유전 경계 격자 역산 제외 또는 별도 침하원으로 모델링 |
| 수로 옆 관측정 기록이 짧음(10/12 발견) | 다층 관측정이 2023~2025년 설치. 장기 비교 불가 | 보정·검증 기간을 2023년 이후로 맞추고, 장기 관측정(수로 4.6~8.6km)은 지역 보정에 사용 |
| 2023년 이후 InSAR 품질(10/12 발견) | DWR InSAR가 2023년 이후 GPS와 반대로(상승) 나옴. 그대로 쓰면 침하를 과소평가 | 2023년 이후 InSAR 제외, GPS로 검증. 서비스에 GPS 교차검증(자료 품질 검사) 기능 포함 |
| 불확실성 과소평가(10/12 확인) | E4 90% 범위가 GPS를 30%만 포함. 계획이 기준을 넘을 위험 | 10/13 대응: 되돌아보기 검증으로 잰 구조 오차를 더해 GPS 포함률 94%. 단 범위 계산이 실제 90%보다 넓게 잡히는 방식이라 다시 계산 필요 |
| 최근 침하 속도 과소예측(10/13 확인) | 검증 기간 GPS 예측이 단순 추세 연장(7.2mm)보다 부정확(E3 20.5mm). 계획 응답도 작게 볼 수 있음 | 단순 예측을 비교 기준으로 항상 함께 보고. 시작 상태(과거 가뭄 잔류 침하)·지연 배수 반영 |
| 가정 우물이 금지구역 안(10/13 확인) | 계획 우물 6개가 수로 양쪽 4km 취수 금지구역 안. 현실성 질문에 취약 | 금지구역 밖 실제 신고 관정으로 교체, ‘전면 금지 vs 관정별 배분’ 비교로 전환 |
| 관리 기준값 근거 부족 | 2mm/3개월은 가정값. “왜 2mm인가” 질문에 취약 | GSP 침하 최소기준(minimum threshold) 등 실제 규제값으로 교체 |
| AI 대리모델 오차(10/13 확인) | AI로 기준선에 맞춘 계획이 MODFLOW에서 7% 확률로 기준 초과 | AI 오차(0.2mm)만큼 여유를 두고 계획 → MODFLOW 확인 0%. 최종 계획은 항상 MODFLOW로 확인 |
