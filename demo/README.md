# AquaLimit 가상 데이터 데모

가상 우물 4개와 침하 관리지점 3개에서, 평균값만 쓴 취수 계획과 불확실성을 반영한 취수 계획을 비교한다. 조건을 만족하는 계획이 없으면 실행 불가를 표시한다.

## 실행

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r demo/requirements.txt
streamlit run demo/app.py
```

## 구성

| 파일 | 역할 |
|---|---|
| `scenario.py` | 가상 지역, 우물별 단위 취수당 침하 응답, 불확실성 시나리오 생성 |
| `optimizer.py` | 선형계획으로 비용 최소 취수 계획 계산, 실행 불가 판정 |
| `evaluate.py` | 계획에 쓰지 않은 시나리오에서 침하와 기준 초과 확률 평가 |
| `app.py` | Streamlit 화면 |

## 가정

- 침하는 우물별 취수량에 비례한다(응답 행렬). 우물 A에서 1,000톤을 뽑을 때 각 관리지점의 침하량(mm)을 거리와 지층 압축성으로 정했다.
- 땅속 특성의 불확실성은 우물 주변 압축성에 곱하는 로그정규 계수로 표현했다.
- 계획용 시나리오(seed 1)와 평가용 시나리오(seed 2, 1,000개)를 분리했다.
- 실제 지역·위성 자료·물리모델은 사용하지 않았다. 다음 단계에서 응답 행렬을 지하수 물리모델 계산값으로 교체한다.
