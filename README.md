# AquaLimit

> 위성 InSAR로 관측한 지표 변형으로 지하 모델을 갱신하고, 모델의 불확실성까지 반영해 취수정별 취수계획을 제시하는 지하수 취수 최적화 엔진.

2026 스페이스 해커톤 출전 후보 · 상태: 기획 단계, 코드 없음

“지반침하 위험을 관리기준 안에 두면서 필요한 물을 공급하려면, 어느 우물에서 언제 얼마나 뽑아야 하는가?”를 계산한다. 조건을 만족하는 계획이 없으면 “추가 용수 확보 없이는 수요를 충족할 수 없다”고 반환한다.
