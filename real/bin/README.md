# MODFLOW 6 executable for Linux hosting

`mf6_6.7.0_linux_x86_64.gz` contains only the `bin/mf6` executable from the
[official USGS MODFLOW 6.7.0 Linux release](https://github.com/MODFLOW-ORG/modflow6/releases/download/6.7.0/mf6.7.0_linux.zip).
The local macOS installation also runs MODFLOW 6.7.0. `cloud_mf6.py` expands
the executable into the temporary directory when the app runs on Linux.
