# 모델 개선 시도 기록 (10/28~11/2)

**결론: 후보 11개 모두 연습 시험에서 v3(수로 2km 14.0mm)보다 나빠, 검증 모델은 v3로 확정한다.** 대신 남은 오차가 어디서 오는지(칸별 분포 / 수로 근처 가뭄 반응 과대)를 나눠 확인했고, 다음 개선은 모델 구조가 아니라 입력 자료(가뭄 해 실제 취수, 유전, 수로 근처 관측)에서 나와야 한다는 근거를 얻었다.

## 1. 판정 규칙 (결과 보기 전에 정함, SCOREBOARD.md와 같음)

- 연습 시험: 2015.7~2019.12로 보정 → 2020~2022 침하 예측, 정답 NASA OPERA, 수로 2km 안 1km 칸 RMSE(mm).
- 채택: 수로 2km RMSE가 v3(14.0)보다 작고, 독립 자료인 GPS P544 RMSE가 v3(21.0)보다 크게 나빠지지 않을 것. 채택된 후보만 최종 시험(2023~2026 GPS)을 한 번 본다.
- 보조 지표: '편향 뺀 나머지' = √(RMSE² − 편향²). 전체 수준(편향)을 빼고 남는 칸별·시점별 오차.

## 3. 알게 된 것

1. **유전 침하 성분은 실제로 있어 보인다.** v4-oil이 Lost Hills 유전 경계에서 연 14~15mm, 1.2~1.3km마다 약 37%로 줄어드는 성분을 범위 끝에 붙지 않고 추정했다. 위성만으로도 수로 2km 안에서 유전에 가까울수록 습한 해(2023)에도 빨리 꺼진다(유전 1km 안 연 23mm, 3~6km 연 4mm, [results_opera/RESULTS_checks.md](results_opera/RESULTS_checks.md) 4절). 습한 해·금지 후에도 계속 꺼진 GPS 4곳(Q198·Q204·Q208·Q213)이 모두 유전 2.5km 안이다.
2. **v3의 14.0mm에는 오차 상쇄가 섞여 있다.** v3는 수로 근처의 '일정하게 꺼지는 몫'이 없어 보정 기간 속도를 낮게 잡고(과소), 가뭄 반응은 크게 잡는다(과대). 속도를 바로잡는 두 방법 — 추세로 고치기(결합 예측)와 유전 성분 넣기(v4-oil) — 이 모두 2022.12 수로 칸 예측을 52~55mm로 넘치게 만든다(정답 46).
3. **칸별 분포는 파일럿 포인트로 줄어든다.** 편향 뺀 나머지 오차 13.9 → 11.7mm, 지역 전체 34.2 → 30.4mm. 3×3 구역 경계 때문에 생기던 오차는 실제로 줄었다.
4. **공통 실패: 수로 근처 가뭄 반응 과대.** 편향이 +8~+12mm로 커진다. 파일럿 포인트 후보 모두에서 수로 남쪽 점 3개(Q208·Q213 근처)가 보정 위성(DWR·OPERA)과 상관없이 압축성 상한(30배) 근처로 간다. 이 모델이 수로 근처의 큰 침하를 만드는 방법이 '점토를 무르게'뿐이라, 가뭄에 반응까지 커진다. 그래서 유연한 후보일수록 보정은 잘 맞고(15.1 → 12.0mm) 예측은 나빠진다.
5. **실제로는 수로 근처가 가뭄에 둔하고 바깥이 민감하다.** OPERA 연 속도: 2020~22 가뭄에 수로 0~1km는 1.34배, 4~10km는 2.98배(RESULTS_checks.md 3절). 모델 입력 취수는 같은 기간 수로 근처 1.37배·바깥 1.24배로, 같은 해 모든 칸의 지하수 비율이 같다. 이를 고치려던 v4-sw2(수로물 깊이 안·밖)는 2015~19 보정 자료에서 가설과 반대 방향(안 0.23 > 밖 0.11m/년)으로 추정됐다 — 이 차이는 2020~22 가뭄에야 뚜렷하다.
6. **보정 위성의 연별 움직임이 다르다.** 보정 기간(2017~2019)에도 같은 칸 DWR와 OPERA의 연 속도가 다르고(수로 띠 DWR 17.3/10.5/17.3, OPERA 12.5/12.5/12.4mm/년), P544에서 GPS와의 연별 상관은 OPERA +0.52, DWR −0.02다(RESULTS_checks.md 5절). OPERA로 보정하면 편향은 일부 줄지만(v4-oil 9.1 → 6.1) 분포 오차가 커져 총점은 비슷하다.

## 4. 다음 단계 (모델 구조가 아니라 입력)

| 단계 | 고치는 문제 | 자료 | 상태 |

| ① 실제 취수 | 수로 근처 가뭄 반응 과대 | 관리기관(WDWA GSA) 계량 기록, 물 공급구역별 수로물 공급량 | 비공개 → 고객 질문 메일에 자료 협력 요청 추가 |

| ③ 유전 침하 | 수로 띠의 일정한 침하 | CalGEM 유정별 생산·주입량 | 공개 여부 확인 필요. 지금 v4-oil은 '일정 속도' 가정 |
| ④ 수로 근처 관측정 | 취수와 점토 성질 구분 | DWR CASP 다층 관측정(2023~25 설치) | 자료가 쌓이면 보정에 사용 |
| ⑤ 파일럿 포인트 재시도 | 칸별 분포 | ①~④ 뒤 | 분포·지역 전체 개선은 확인됨 |

## 5. 재현

```bash
cd real
bash run_dev.sh v4-oil v4-oil-hw v4-oil-aq v4-pp v4-oil-pp v4-sw2 v4-oil-pp-sw2      # DWR 보정 후보(후보당 5~12분)
for v in v3 v4-oil v4-pp v4-oil-pp; do AQ_INSAR=opera AQ_VARIANT=$v python3 run_real.py --dev; done   # OPERA 보정 후보
for v in ...; do [AQ_INSAR=opera] AQ_VARIANT=$v python3 rescore_practice.py; done   # OPERA 정답 채점
python3 rescore_practice.py --table && python3 scoreboard.py
python3 opera_checks.py                                                             # 위성 점검(몇 초)
```

변형 이름은 `-`로 이어 붙인다(`real_model.py` 맨 위 설명): oil(유전 성분), hw(수위 가중치), aq(수로 띠 배수), pp(파일럿 포인트, `AQ_PP_LEN`·`AQ_PP_CORR`), sw2(수로물 안·밖). 보정 위성은 `AQ_INSAR=opera`. 새 변형은 켤 때만 작동하고 v3 계산은 바뀌지 않는다(취수·함양 입력 동일 확인).
