# 실제 검증 지역 취수 계획 (2026년 5~7월, 시뮬레이션)

사업자 우물 6개 = DWR 신고 농업용 우물 중 취수 금지구역(수로 양쪽 2.5마일) 밖 실제 우물(용량 합 48,841 m³/일), 3개월 수요 3,370,026 m³, 외부 용수 0.81$/m³(한도 1,123,342 m³). 관리 기준: 계획으로 인한 수로 칸(38곳) 추가 침하 ≤ **2.0mm/3개월**. 참고로 배경 침하(다른 농가 취수)만으로 수로 칸 중앙값 8.6mm, 최대 17.6mm가 3개월 동안 생긴다.

우물 위치·깊이는 실제 신고 자료, 양수량은 신고값(없으면 신고 중앙값), 비용은 정수위 + 양수 강하 깊이의 전력비다. 관리 기준(3개월 추가 침하 한도)은 연 0.5인치 수로 기준 중 이 사업자 몫으로 둔 가정값이다. 땅속 성질·배경 취수·함양은 실제 자료로 역산한 값을 쓴다. 실제 정답이 없으므로, 각 계획을 **E4 앙상블 30개 모두에서** 계산해 기준 초과 확률로 비교한다. 주의: E4 계획은 바로 이 30개 모두에서 기준을 지키도록 만든 것이라 E4의 0%는 정의상 0%다(표본 내 값). 계획에 쓰지 않은 땅속 상태로 다시 잰 값은 `eval_plan_oos.py` 결과(RESULTS_oos.md)를 본다.

**임계수위(과거 최저 수위)는 이 사업자의 계획으로 지킬 수 없다.** 계획 우물을 하나도 안 돌리고 수요 전량을 외부에서 사도, 다른 농가의 배경 취수만으로 수로 칸 수위가 이미 과거 최저보다 낮다(앙상블 100%). 그래서 모든 계획에서 '임계수위 아래로 내려갈 확률'이 100%로 나온다. **지역 전체(지하수 관리기관) 차원의 취수 조정이 필요하다**.

### 해석

- **E1(용량 비례)**은 모델 없이 고르게 뽑아 비용 229천$, 기준 초과 확률 37%.
- **E3(위성 + 추정값 1개)**는 싸고 침하 영향이 작은 우물로 옮겨 비용을 209천$로 줄이지만, 기준선에 딱 맞춰 계획해서 초과 확률이 33%다. 실제로 MODFLOW로 직접 돌리면 최대 1.77mm로 기준(2mm)을 넘는다(2절).
- **E4(불확실성 반영)**는 외부 용수 886천 m³를 사서 비용이 874천$(E3보다 318% 높음)이지만, 앙상블 30개 모두에서 기준을 지킨다(초과 확률 0%).
- 가상 대수층 실험(synthetic/)과 같은 결론이 실제 지역 모델에서도 나왔다: 추정값 하나만 믿으면 기준선에 붙고, 불확실성을 반영하면 비용을 더 써서(이 조건에서는 외부 용수 구매 때문에 비용 증가가 가상 실험보다 크다) 위험을 없앤다.
