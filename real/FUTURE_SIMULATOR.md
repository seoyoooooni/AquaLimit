# 미래 시뮬레이터: 발표와 계산 기준

## 발표에서 보여 줄 순서

1. ③ 우물별 시뮬레이터를 열고 상단에서 **미래 월별 계획**을 고른다. **2026년 5~7월 과거 실험**도 같은 곳에서 전환할 수 있다. 미래 계획의 기본값은 **2026년 11월 시작, 3개월, 평년 시나리오, 실제 신고 우물 6개**다. 이 조합은 미리 계산되어 바로 보인다.
2. “지난 계획은 2026년 5~7월 동안 같은 하루 취수량을 적용했습니다. 이번에는 시작 월과 기간을 고르고, 11월·12월·1월의 우물별 취수량을 따로 결정합니다.”
3. 월별 표에서 취수량이 바뀌는 것을 보여 준다. 검은 점선은 기간이 길어지며 누적되는 추가 침하 허용량이다. 색 선은 세 가지 지층 상태에서 예상한 **이 사업자 계획의 추가 침하**다.
4. “이 값은 2026년 11월에 관측한 침하가 아닙니다. 마지막 모델 입력은 2026년 4월이고, 그 후의 날씨와 수로물 배분은 시나리오 가정입니다.”라고 분명히 말한다.
5. `월별 수요와 비용 설정`에서 한 달의 수요를 바꾸면, 물리 응답을 다시 계산하지 않고 월별 계획이 즉시 바뀐다. 시작 월·기간·날씨·우물을 바꾸면 `선택한 기간의 미래 계획 계산`을 눌러 MODFLOW 응답을 새로 만든다. 이 계산은 몇 분 걸릴 수 있다.

## 계산 방식

- 기준 모델: `real_model.py`의 `v3ops`, 2026년 4월까지. 지층 파라미터는 기존 E4 앙상블의 구성원 3개(선택 가능)를 사용한다.
- 시작 월 전까지의 공백은 선택한 날씨·수로물 배분 시나리오로 계산한다. 이 기간에 사업자 우물은 신고 용량의 75%로 운영했다고 가정한다.
- 계획 기간에는 각 **월 × 우물**을 한 번씩 단독으로 가동해 수로 관리지점의 월말 침하 응답을 MODFLOW로 구한다. 각 응답을 합쳐 월별 취수량과 외부 용수 구매량을 비용 최소가 되도록 정한다.
- 매월 수요를 채우고, 우물 용량과 외부 구매 한도를 지키며, 모든 선택된 지층 상태·관리지점·월말의 사업자 **추가 침하**가 `2.0mm / 92일`에 비례한 누적 한도 이내가 되게 한다. 이 한도는 사업자에게 할당한 **가정값**이다. 실제 규제 인증값이 아니다.
- 화면의 `0/3개 모델`은 최적화에 사용한 세 구성원의 표본 내 결과다. 실제 초과 확률이 아니다. `MODFLOW로 직접 검증`을 누르면 완성된 월별 계획을 물리 모델에 다시 넣어 선형 응답 근사와 비교한다.

## 기본 시연 결과

2026년 11월~2027년 1월, 평년, 월별 수요 75%, 여유 25%에서 총비용은 약 **$261천**, 외부 용수는 약 **69천 m³**다. 우물 D·E는 11월 계획에서 쉬고, 12월과 1월에는 다시 배분이 바뀐다. 세 구성원 모두 추가 침하 한도 이내였다. 완성된 계획을 MODFLOW로 직접 다시 실행했을 때 선형 응답과의 최대 차이는 약 **0.013mm**였다.

이 결과는 2026년 4월 이후 관측을 재동화한 실시간 예보가 아니다. 실제 운영에 쓰려면 최신 강수·증발산·수위·GPS·수로 배분율과 우물별 계량 취수량을 반영해 모델을 갱신하고, 독립된 미래 기간으로 다시 검증해야 한다.
