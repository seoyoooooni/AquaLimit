# 위치 입력 AI 대리모델

입력: 땅속 성질 + **우물 위치**. 출력: 그 위치에서 하루 1,000m³를 3개월 뽑을 때 수로 38곳 추가 침하·수위 변화. 우물 위치가 바뀌어도 다시 학습할 필요가 없다.

## 1. 정확도

| 항목 | 값 |
|---|---|
| 학습 자료 | MODFLOW 1000회 (땅속 상태 200개 × 위치 4곳 + 기준) |
| 처음 보는 땅속 상태·위치 오차 | 0.0073 mm (최대 응답 평균 0.075 mm, R² 0.920) |
| 실제 사업자 우물 6곳, MODFLOW 응답 행렬과 차이(우물 용량 기준) | 0.018 mm (응답 크기 평균 0.209 mm) |

## 2. 속도

| 계산 | 시간 |
|---|---|
| MODFLOW 1회 | 5.8 초 |
| AI: 농경지 432칸 전부의 영향 지도 | 1 ms (MODFLOW로는 433회 ≈ 42분) |
| 땅속 상태 1,000개 × 우물 6곳 응답 | AI 0.0 초 / MODFLOW 약 11.3 시간 |

## 3. AI로 땅속 상태 1,000개 강건 계획 → MODFLOW 30개로 확인

- AI 계획: 비용 1,213천$, 외부 구매 1,339천 m³
- MODFLOW 확인 기준 초과 확률 0%
- AI 오차 여유(0.06mm)를 둔 계획: 비용 1,256천$, MODFLOW 확인 기준 초과 확률 **0%**

## 4. 주의

- AI는 MODFLOW를 흉내 낸다. 학습 범위(E4 사후분포 2배 폭, 평년 조건, 농경지 칸) 밖은 보장하지 않는다. 최종 계획은 MODFLOW로 다시 확인한다.
- 여러 우물은 단위 응답을 더한다(선형 중첩). 우물이 많고 취수가 크면 MODFLOW 확인이 더 중요하다.

계산 시간 0.2분.
